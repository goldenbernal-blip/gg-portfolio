# Glass Garden Asset Map

The portfolio uses the files in `assets/glass-garden/` as one layered world.
Keep this folder beside `index.html` when publishing.

- `glass-garden-main-01.png`: primary desktop garden scene
- `glass-garden-main-02.png`: tablet atmosphere fallback
- `glass-garden-main-03.png`: closer mobile garden scene
- `glass-garden-main-04.png`: subtle bloom/depth scene
- `glass-garden-main-05.png`: optional future full-garden fallback
- `glass-garden-mist-overlay.png`: reserved optional atmosphere layer
- `glass-garden-wing-left.png`: reserved optional wing asset
- `glass-garden-wing-right.png`: reserved optional wing asset
- `glass-garden-flower-growth.png`: scroll-controlled flower growth
- `glass-garden-petals-overlay.png`: drifting transition petals
- `glass-garden-refraction-overlay.png`: modal atmosphere and optional shimmer

For smooth scrolling, the live background intentionally uses only the main
scene, flower growth, petals, atmosphere, and foreground layers. The remaining
assets are kept as optional future layers rather than running continuously.
