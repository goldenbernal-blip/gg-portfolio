Field Merchandising Intelligence System
End-to-End Operational Reporting · Automated
Three sources. Zero manual steps.
One live dashboard.
Field activity was being captured across separate tools, inboxes, and file formats, which made reporting slow and incomplete. I built the automation layer that brought those inputs together, standardized the records, and turned them into a live operational view the team could use.
Google Apps Script Google Sheets Vercel HTML / CSS / JS Email Parsing PowerPoint Processing Automation Architecture
Live consolidated sheet Field Sales Tracker
01   The Problem
Field visit information existed, but it was scattered across formats that did not talk to each other. Visit notes lived in a Google Sheet. Task completions arrived by email. Store recaps and photos were buried inside PowerPoint files from a third-party merchandising partner. The team needed one trusted view, but the work required to assemble it manually was too slow to sustain.

02   The Three Sources
Each source carried useful information in a different shape. This was not a simple spreadsheet formula problem; it required parsing each input format, extracting the fields that mattered, and normalizing the results into one reporting structure.

Internal Team

Store visits logged manually by the field sales team. This was the internal reference point, but it was isolated from email updates and third-party recap files.

Google Sheet

Skyu / Circle K

Task completions sent to a shared inbox. The useful visit data was present, but every message had to be identified, parsed, and structured before it could be reported.

Email Inbox

Advantage

Third-party merchandising recaps delivered as PowerPoint files. Notes and photos were embedded inside the files, which meant the reporting system needed a separate extraction path.

PowerPoint Files
03   The Architecture
The final architecture stays lightweight on purpose. Google Apps Script handles the daily sync and photo extraction, the consolidated sheet becomes the source of truth, and the dashboard reads from a published CSV. No database, no backend server, and no ongoing hosting cost.

04   The Automation Layer
The pipeline is designed to run quietly in the background. Once the sources are available, the scheduled trigger handles collection, parsing, cleanup, and refresh without asking the team to remember another admin step.

Daily Scheduled Trigger

Apps Script runs automatically every day. No manual trigger needed. The data stays current without anyone touching it.

Email Parser for Skyu / Circle K

The script reads the shared sales inbox, identifies completion emails by pattern, extracts the relevant fields, and writes them into the consolidated sheet.

PowerPoint Photo Extractor

A separate script opens Advantage PowerPoint files from Google Drive, reads the binary structure, extracts every embedded image, names each file by store, and links them back into the sheet automatically.

Deduplication and Structuring

All three inputs are normalized into a consistent column structure. Duplicate entries are removed. The sheet stays clean without any manual cleanup.

05   The Single Source of Truth
One consolidated Google Sheet receives every store visit from every source. It stays current through automation and publishes as a live CSV, which the dashboard fetches on load. The sheet acts as the data layer, keeping the system simple and maintainable.
Always current Updated automatically every day. The dashboard reflects what happened without anyone needing to push a sync.
Published as live CSV Google Sheets publishes the data as a public CSV endpoint. The dashboard reads it on every load. No backend required.
Photos linked by store Every photo extracted from the Advantage PowerPoints is named by store and linked directly in the sheet row for that visit.
Access-controlled The sheet is accessible to the team. The dashboard has a password-protected admin layer for configuration settings.
06   The Dashboard
The dashboard is a single web page deployed on Vercel. It reads the live CSV and turns the consolidated sheet into a searchable, filterable, interactive view of field activity. It is the usable layer on top of the automation.
Date Filters This week, this month, this quarter, all time, or a custom date range.
Flagged Findings Out of stock, no inventory, and reorder alerts auto-surfaced and clickable to the source row.
US State Map Interactive map of Advantage coverage. Click any state to filter visits by location.
Store Photos Embedded inline with pagination. Photos are linked from Drive and display inside the dashboard per visit.
Fully Responsive Works on phone and desktop. Built with the team in the field in mind.
Admin Settings Password-protected admin panel for configuration. Separate from the main read view.
Photos currently link to the source Drive folder per visit. A future iteration will embed them directly inside the dashboard using the Google Drive API, removing the need to open a separate tab.
